## 一、为什么现在做（产品诉求）

- 织卷用 custom 标题栏（`titleBarStyle: 'hiddenInset'`）且主进程**未注册应用菜单**（src/main 无 Menu 代码）——当前显示 Electron 默认英文菜单，快捷键可发现性只靠 ⌘K 面板「帮助→键盘快捷键速查」与设置页「关于」（docs/快捷键.md 备注）。
- HIG Keyboards：快捷键应当随菜单可见；HIG The menu bar 开篇：macOS 用户依赖菜单栏学习 app 能力。接入标准菜单栏＝补齐 mac 生态惯例，属质感主线「平台规范」部分；菜单是系统 chrome，系统渲染即与暖纸设计语言自然协调。
- 不推倒 ⌘K：命令面板承担「搜索+动作中枢」，菜单承担「发现+标准编辑命令」——双轨并留，菜单是增补入口而非替换（HIG「即时按钮不重复砌」。同理页面内按钮/右键菜单/划词浮层一律保留）。

## 二、菜单栏结构（织卷版）

顺序照 HIG Anatomy：**织卷 / 文件 / 编辑 / 格式 / 显示 / 窗口 / 帮助**。
（HIG 只规定「App名、File、Edit、Format、View、App-specific、Window、Help」的顺序；中文 macOS 惯例为 文件/编辑/格式/显示/窗口/帮助，View=「显示」。）

### 首期明确不做（记录理由，防反复）

- **格式菜单**：HIG「无格式化支持可省略」；织卷加粗/斜体已有工具栏与 ⌘B/⌘I（Milkdown），且格式命令走菜单需处理 ProseMirror 命令映射（同撤销风险），首期收益<成本。后续候选：加粗/斜体两项（自定义 send 到 editor 命令）。
- **App-specific 顶级菜单**：HIG 只在自定义命令多时才建；织卷自定义命令少（查找/速查/文档目录），已融入编辑/帮助。克制，不加。
- **「添加到对话」进编辑菜单**：右键菜单/划词浮层已全覆盖（I1, 2e79d48），且系统菜单点击会转移焦点、选区上下文不可靠，重复入口收益低。
- **打开最近项目**：HIG File>Open Recent 是标准项，但需 `app.addRecentDocument` 接入且织卷有自研 `main/recent.ts`（另一套口径）；登记为二期候选（数据源统一后再做）。
- **显示/隐藏侧边栏**：依赖 I4 侧栏可隐藏（功能=平台层，候选 2 已登记）；功能落地后按本表「显示」组插入（toggle 项：当前可见→「隐藏侧边栏」，隐藏→「显示侧边栏」，HIG toggled item 口径）。

## 三、统一口径（写死，违反=返工）

1. **菜单名**：单字/短词（HIG「Prefer short, one-word menu titles」）：文件/编辑/显示/窗口/帮助。App 菜单标题=「织卷」（HIG app 名 ≤16 字符→合规；未设 productName 时用 label 硬编码）。
2. **项 label**：动作一律动词开头（新建/保存/查找/最小化…）；需要额外信息才能完成才加「…」（新建项目…/设置…/查找…/关于织卷…），纯动作不加（保存/全选/切换全屏）。全部显式中文 label（Electron role 默认英文，macOS 上 role 项 `label` 与 `accelerator` 是唯二生效的自定义项——官方确认，其余选项被忽略）。
3. **不可用=灰显不隐藏**（HIG The menu bar「Always show the same set of menu items」+ Menus「Show people when a menu item is unavailable」）；子菜单标题在成员全灰时保持可用（HIG「Make sure a submenu remains available」）。
4. **编辑基础命令用 Electron role**（HIG Edit menus「Prefer the system-provided edit menu」；Electron「built-in role behavior will give the best native experience」）。label 用中文覆盖。
5. **不新增任何快捷键**（HIG「Define custom keyboard shortcuts only when necessary」）：菜单只承载 docs/快捷键.md 已有组合 + 系统标准（⌘, 设置/⌘W 关窗/⌃⌘F 全屏/⌘M/⌘0/⌘+/⌘− 这些此前织卷没有但属 macOS 标准，允许）。新增快捷键=先改 docs/快捷键.md + ShortcutHelp + 本表三处。
6. **菜单是发现入口，不替换** 页面按钮 / ⌘K / 右键菜单 / 划词浮层；不新增顶级自定义菜单。
7. **动作分发**：自定义项 click → `win.webContents.send('menu:action', { id })`；preload 暴露 `onMenuAction(cb)`；渲染层 App 级**单点分发**（App.tsx 一处 switch，按 id 调各域 store/动作；页面跳转用 `window.location.hash`——路由外组件别用 react-router hooks，EngineBadge 旧坑）。**例外（主进程侧动作，不 send）**：`关于织卷…`（menu.ts onAbout：setAboutPanelOptions + showAboutPanel）与 `打开说明文档目录`（menu.ts onOpenWorkspaceDocs：`shell.showItemInFolder(工作区/文档)`）——前者可直接弹，后者按 §四动作地图「主进程直接」处理。禁用状态：主进程维护 `enabledMap`（由渲染层经 IPC 上报当前页/可保存性等）或按 webContents URL 判断。
8. **文案**与 docs/文案口径表.md 对齐（「新建项目/新建章节」动词口径已定；新增术语先改口径表）；「快捷键速查」等词与产品词一致。

## 五、风险与验证点（平台层落地时必须实测，属验收项）

1. **⌘S/⌘F/⌘G/⌘E 双触发**：菜单 accelerator 注册后按键由主进程菜单体系处理；**是否仍向 renderer 派发 keydown 未达官方明文**（Electron keyboard-shortcuts 教程只说明 menu accelerator 触发 click，未说明 renderer 事件去向）。验收 (b)：菜单落地后按 ⌘S/⌘F 各一次，确认（i）动作发生且（ii）**只发生一次**（无「保存双写/查找条开合两次」）。若双触发→渲染层对应 keydown handler 改为「菜单已接管」时跳过（主进程 send 一个状态/或渲染层检测 `menu:action` 前缀时间戳），或以菜单 click 为唯一入口、删渲染层 keydown。
2. **role undo/redo/⌘B 与 ProseMirror**：role 编辑命令走系统通道（`webContents.undo()` 等，可能经 `execCommand`），**不保证经过 ProseMirror history/commands**（Milkdown 的 ⌘Z 是 keymap 处理的）。验收 (c)：编辑器内输入→菜单「撤销」→确认 ProseMirror undo 生效且 undo 栈不碎；若不生效→撤销/重做改自定义 send（ProseApi 暴露 `undo()/redo()`），或保留 role 但删 keymap 冲突（二选一，以实测为准）。
3. **选区/上下文丢失**：点击系统菜单会使焦点离开 webContents；`save`/`findUseSel` 等依赖当前文档/选区的动作，需在 renderer 侧以「最近文档状态」而非「事件时 DOM」为准（save 已有 doc 上下文，风险低；findUseSel 用 ⌘E 已不复现）。
4. **锁屏无法验收菜单**：系统菜单是 OS chrome，无头 CDP 截不到、点不到。验收以「主进程模板断言」（esbuild 冒烟：`Menu.buildFromTemplate` 结果逐项 label/role/accelerator/enabled 比对）+ 真机解锁后主人过目为准；截图轮不着要求（回执注明）。
5. **禁用态来源**：主进程与渲染层状态同步（当前页/编辑器挂载/可保存）必须一条通道（IPC 上报），避免两处各判。

## 六、验收口径（平台层落地轮，逐项打勾）

- (a) 冒烟断言：菜单模板结构=织卷/文件/编辑/显示/窗口/帮助（顺序、label 逐字=本表第二列——其中「查找 ▸」为带子菜单项，实现 label=「查找」，箭头由 macOS 系统渲染）、role 与 accelerator 逐项=本表、自定义项 click 发出 `menu:action{id}`（mock webContents 捕获；**关于/打开说明文档目录两例=主进程侧动作断言**，见 §7 例外）。
- (b) ⌘S/⌘F/⌘G/⌘E/⌘B 按下各只触发一次动作（双触发检查，含无编辑器时灰显路径）。**渲染层去重已收口（2026-09-14 平台层）**：共享纯函数 `shared/menuDedup.shouldSkipKeydown`（750ms 窗口）+ 单测 6 例 + 无头冒烟「菜单 save 后窗口内 ⌘S 不双保存」负向断言；真机 ⌘S/⌘F/⌘G 键盘实测仍待解锁（候选 3 ⑤，见 03-平台层.md）。
- (c) 编辑器内撤销/重做/剪切/复制/粘贴/全选经菜单可用且 ProseMirror 正常（`undo/redo` 走 role 或已改 custom，以实测结论为准）。
- (d) 文档外（Home/Settings 等）⌘F 相关项灰显、保存灰显；子菜单仍可点开；app 菜单 About/Hide/Quit 标签含「织卷」。
- (e) 菜单中文文案与本文档逐字一致；省略号规则符合（新建项目…/设置…/查找…/关于织卷…；其余无…）。
- (f) 三道门绿 + 既有无头冒烟（渲染层组件不动→全过）。
- (g) 真机解锁主观过目（菜单展开截图/录屏）。
