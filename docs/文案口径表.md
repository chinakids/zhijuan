# 织卷 · 文案口径表（术语一致性台账）

> 依据 Apple HIG「Writing」：*Create a list of common terms, and reference that list to keep your language consistent.*（https://developer.apple.com/design/human-interface-guidelines/writing）
> 本表由体验层 2026-09-12 轮建立（W3 文案一致性体检的产物）。**任何新文案先查本表；引入新术语先改本表再写**。权威在仓库，别凭记忆。

## 一、术语 → 统一用词

| 概念 | 统一用词 | 允许的语境变体 | 禁止（已排查无残留） |
|---|---|---|---|
| agent/模型会话 | **写作引擎** | 状态徽章/离线提示可简称「引擎」；代码与内部技术文档可写「dsh 引擎 / 边车」（D-V2-6） | 面向用户的「助手/边车」等 |
| 章节文件（`正文/第NN章_题名.md`） | **正文** | 栏目名「正文创作」 | 稿件、文稿 |
| 作品里的人 | **人物** | 「人物设定」（侧栏/模块名）、「人物档案」（页面组头/按钮）、「涉及人物」（约定头字段） | 角色档案、每个「角色」 |
| 素材 | **素材**（素材库 / 素材卡 / 素材文档） | 采集动作「发起采集」「采集素材」 | 资料（「采集资料」已改） |
| 大纲副产物（章卡/导演板） | **章卡** | 「大纲」＝目录名，非产品词 | 大纲卡 |
| 时间切片 | **切片** | 「每章一个时间切片」「切片名写进约定头」 | 场景/节点 |
| 世界观切片文件 | **`世界观/切片_<切片名>.md`** | 引擎侧兼容无前缀旧名（只读兜底），新写入一律带前缀 | `世界观/<切片名>.md`（说明文档曾这么写，已改） |

| 切片同步的历史留痕 | **同步记录** | 抽屉副文本「每次比对都记在这里」；按钮文字「同步记录」 | 同步日志、同步历史 |
| 已退出活跃流的世界切片文件标注 | **历史**（徽标） | 完整表述「保留为历史，不再参与后续同步与创作上下文」（改名 Dialog/toast 既有文案） | 旧切片 / 停用（徽标用词） |
| 口头禅/AI 腔高频短语检查（本地规则第 8 项） | **用词重复核查** | 检查菜单短名「用词」；内部 type=overuse | 用词频率检查 / AI 腔检查（用户层文案勿用） |
| 作者自行维护、与内置词表合并观察的短语清单 | **自定义用词词表** | 档案/代码可写「自定义词表」，内部字段 settings.overuseDict；设置项语境「自定义用词词表」 | 自定义词典（Grammarly 语义=拼写豁免，语义不同勿混用） |
| 作者沉淀的写作方法/流程资产（含约定头的 markdown 指令文件，工作区 skills/） | **技能包** | 设置卡标题/导入导出「技能包」；列表行与 / 命令菜单简称「技能」；命令卡徽标「技能」；内部字段 skills/*/SKILL.md | 技能库 / 提示词库 / 模板（误指命令模板） |

## 二、不动语境词（有意保留，勿当残留）

- **角色粉**（多视角审视的观众定名：角色粉视角 / 设定党视角 / 节奏读者视角——同人惯用，「人物粉」不成立）
- **示例角色**（内建「示例」模板里的人物名，贯穿文件名/约定头/档案内容，属数据一致性，不动；模板说明文字用「人物档案/主要人物」）
- **主角**（文学通用，「与主角关系」等）
- **人设**（内部 prompt / 创作语境）
- **设定档案 / 设定**（泛称，指人物档+世界观档+切片档）
- **建档案 / 为 N 名人物建档案**（守卫「未建档」人物就地快速建档的动作词（03:45 确立）：浮层逐条按钮、toast 批量按钮、结果文案、失败提示「建档案失败」统一用此词——「新建人物档案」保留给 Characters 页创建入口的占位提示语境，两语境勿互改）
- **已有档 / 已有档案未改动**（2026-09-22 03:45 确立=快速建档发现档案已存在（未覆盖）时的状态词：浮层徽标「已有档」、逐条 reason「已有档案未改动，重新触发同步后不再拦截」、toast 摘要「N 名已有档案未改动」统一用此词——与「已建档」（实际新建）严格区分，防作者误以为新建了档案）
- **提案**（D-V2-3 产品词，确认后应用）

## 三、标点与空格规则（UI 文案层）

> 依据 Apple HIG Writing「Be clear / consistent」（https://developer.apple.com/design/human-interface-guidelines/writing）＋ 中文文案排版指北（https://github.com/mzlogin/chinese-copywriting-guidelines）。2026-09-12 体验层第二波体检建立。

| 规则 | 口径 | 例外 |
|---|---|---|
| 中英文/中数之间 | **加一个空格**（如「写 3 章」「256 字」「Milkdown 编辑器」） | 路径/代码引用（`正文/第NN章_题名.md`）、英文单词内部、链接 |
| 标点 | **全角中文标点**（，。！？：「」（）） | 数字、英文、代码、路径内用半角 |
| 示例分隔 | 中文句子里列举用**全角逗号**（如「如：林晚，顾知远」） | 输入值域提醒与解析 split 兼容（/[,，]/） |
| 重复标点 | **不连用**（！！？？ 禁止） | — |
| 数字 | 半角；**% 与数字间不加空格**（15%） | 中文数词用汉字 |
| 按钮/错误提示动词 | 统一**「新建 X / 新建 X 失败」**（新建项目/新建章节/新建素材/新建类别/新建人物档案/新建第一章） | 说明性陈述可写「生成」（导演板生成/分幕草稿已生成） |
| 动作结果句式 | 成功「已 X」（已保存/已重命名/已移入废纸篓）、失败「X 失败」（动词+对象+失败） | — |
| 空态句式 | 统一「还没有 X」；命令/搜索无结果统一「没有匹配的 X」 | — |
| 引用页面按钮 | 写**按钮文字**（如「点右上角「新建第一章」」），不写图标形状（「+」） | — |
| 人物指代 | 用户可见提示用「TA」（HIG 包容性写作），不加引号 | 正文/设定内容除外 |

## 五、落地记录

- 排查面：`src/renderer/src/**/*.tsx` + `src/main/{store,workspace-docs,templates}.ts` + `src/shared/{presence,commands}.ts` + `scripts/*.mjs`（冒烟断言）。
- 结论：五对候选术语中 4 对（写作引擎/边车、正文/稿件、素材/资料、章卡/大纲卡）仅剩 1 处残留（说明文档「采集资料」）；**人物/角色**为真实混用（页面标签、引导、示例模板、说明文档、在场核查建议语），全部收敛到「人物」。
- 同时修正：说明文档世界观切片文件名与真实约定（`切片_<名>.md`）不符；引导「角色」系列文案；`/延伸`命令提示词「角色动机」→「人物动机」。

### 第二波（2026-09-12 17:15 体验层轮）：标点/空格 + 动词句式

- 排查面：`src/renderer/src/**/*.tsx` 全部用户可见文案（title/placeholder/aria-label/JSX 文本/toast/空态/提示）+ 解析函数（`split(/[,，]/)`）核对。
- 依据：HIG Writing「Be clear / consistent」＋ 中文文案排版指北（中英文/中数空格、全角标点、不重复标点、数字半角；来源 URL 见第三节引言）。
- 落地 8 处（提交见模块档案）：① 建章对话框占位「如：林晚, 顾知远」→「林晚，顾知远」（`split(/[,，]/)` 兼容）；② 采集关键词占位「如：旧图书馆, 借书卡」→「旧图书馆，借书卡」；③ 正文空态「点右上角「+」开始第一章」→「点右上角「新建第一章」开始」（引用按钮文字，与首页「点右上角「新建项目」」句式一致）；④ toast「创建项目失败」→「新建项目失败」（与「新建项目」对话框动词一致）；⑤ 新建类别错误兜底「创建失败」→「新建类别失败」；⑥ Agent 面板「导演创建失败」×2→「导演板生成失败」（与大纲页「导演板生成失败」/产品词「导演板」一致）；⑦ 命令面板空态「没有匹配项」→「没有匹配的结果」（与 AtMention/CommandMenu「没有匹配的 X」句式一致）；⑧ 世界观空态「总纲在项目创建时已生成」→「总纲在新建项目时已生成」。
- 未动（记录观察）：设置页 toast「说明文档已就位（无需重复创建）」系重建语境陈述，保留；冒烟脚本断言里的旧文案随脚本更新。
