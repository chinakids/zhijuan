## 三、长远规划

- 定位主线：**人与 agent 协作的创作工作台**——agent 是检查与调度的执行者，织卷负责边界（版本/采纳/提案/存档）。每轮审视：检查必须有**处置入口**（审读→让 agent 改、兑现→重写段），结论必须**落资产**（审读存档）。
- 待回接/待评：V1 分幕其余能力（行为轴已由导演板 axes 覆盖、回滚到某幕重生成）；「用织卷真的写完 5 万字且前后自洽」大验收（迭代原则 §四）。
- 机械层（确定性审查）是已确定的方向：presence 之后，称谓一致性/切片顺序核查等按候选逐个加；不引重量级依赖、秒级零 token 是红线。
