## 三、长远规划

- **主人 2026-09-10 拍板（本模块当前主线）**：
  1. **对话流功能体验**——流式加载（渲染顺滑、思考折叠、事件流稳定）、工具显示（活动卡各状态：进行中/成功/失败/被跳过/耗时/参数展示，TodoCard/AskCard/EditCard 一致性）、输入框 **@ 功能**（@人物/章节/素材/文档 → 注入引用或上下文）、**skill 功能**（命令槽位/技能调用入口，如 /续写 /巡查 /导演）。

- 定位主线：**人与 agent 协作的创作工作台**——agent 是检查与调度的执行者，织卷负责边界（版本/采纳/提案/存档）。每轮审视：检查必须有**处置入口**（审读→让 agent 改、兑现→重写段），结论必须**落资产**（审读存档）。
