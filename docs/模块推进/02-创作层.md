## 一、模块定位与边界

- 覆盖：正文创作页（编辑器 Milkdown/Prose、章节列表、章节向导、保存链路）、**保存 → 时间切片同步**（正文为源、设定为流，出提案）、**提案系统**（.zhijuan/proposals/，锚点校验 + stale 检测）、**人物/世界观设定文档与切片约定**（front matter、切片目录、.zhijuan/slices.json 清单、时间线视图）、**正文写入口径**（zj_edit_doc 修改卡、doc:adoptActs 采纳、约定头保留）。
- 权威源章节：模块设计-V2 §2.2/§2.3/§6、§七/§八、§十（G）、§十四之（约定一）、架构评审 §一/§三。
- 边界外：agent 检查/导演能力本体（智能层）；采集管道与素材库（平台层）；视觉组件（体验层）。跨边界改动先在其档案登记。

## 三、长远规划

- V2 核心闭环：**「先设定后成文」（导演板→分幕→采纳到正文）与「先文沉淀设定」（保存→切片同步→提案）双向打通**；正文是唯一源，约定头是唯一半结构化约定。
- 大验收（ROADMAP §四）：用织卷真的写完 5 万字且前后自洽——创作层的角色是把「从新建项目到正文落定」的链路做到顺滑、可重复。
- 待评估：目录/大纲区与正文创建流程的引导（新项目初始化 flow）；正文版本历史（M3，供审阅/回滚）。

## 四、迭代日志

- **2026-09-09（跨层登记，由体验层发现并顺手修复，提交 285360d）**：`Novel.tsx` 新建章节后 `setSel('正文/'+name)` 带前缀，与 `listChapters` 返回的 `file`（listDocs 相对 `正文/` 的裸名）不一致 → 新建后 `sel` 匹配不到列表（不高亮）、`chapterRel='正文/正文/…'` 让 DocEditor 读空路径。修复：`setSel(name)`（裸名），与 refresh 后列表对齐；本次同时为 ⌘K「打开章节」加了 `?ch=` 定位（见体验层档案）。
