## 一、模块定位与边界

- 覆盖：UI 设计系统（模块设计-V2 §13：Tailwind v4 + shadcn/ui + Milkdown；设计语言「暖纸面（Notion 系）+ 精密中性铬（Linear 系）混合」；组件清单）、三大色板主题（暖纸/墨色/青黛）、各页面交互打磨（窄窗口不换行、custom 标题栏右留白、按钮层级、空态/加载/错误态）、**引导 flow**（新项目初始化、功能发现）、无头 UI 冒烟脚本的回归覆盖。
- 权威源章节：模块设计-V2 §13、ui-ux-pro-max 技能（织卷用它的本机规则库）、zhijuan-app 技能 UI 约定、M5 编辑页瘦身经验。
- 边界外：功能实现本身（对应智能/创作/平台层）；体验层只做呈现与交互细节，改动须经三道门 + 无头冒烟。

## 三、长远规划

- 设计语言是「暖纸面 + 精密中性铬」混合：内容区温度、工具区精度；新页面先对照设计系统再写，不随手造样式。
- 每条新交互（含智能层/创作层新增的抽屉、按钮）都要过一遍：窄窗口、空态、加载态、错误态、键盘可达；无头冒烟脚本要跟上。
- 「用织卷写完 5 万字」大验收中的体验部分：流程顺滑、无歧义文案、功能可发现。
