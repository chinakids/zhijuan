## 一、模块定位与边界

- 覆盖：首页项目管理（新建/导入/列表）、工作区外壳（侧栏四大板块定位）、素材库页面与**联网采集管道**（任务卡 front matter 约定 + 本机管道 cron 76de7e949a3b 回填）、设置页（模型厂商/引擎开关/主题）、代码工程面（store/settings/slices 等数据层、路径约定、构建/打包、项目模板、依赖与依赖治理）。
- 权威源章节：模块设计-V2 §四（A）/§五（B）/§九（F）/§十一（H）/§十二（I）、§十四、架构评审 §二（store 上帝文件）。
- 边界外：编辑器与设定内容（创作层）、agent 能力（智能层）、视觉细节（体验层）。采集管道 cron 是采集系统本体，推进器只改织卷侧（表单/任务卡/回填逻辑）。

### 2026-09-09 22:33 起（第 2 轮：候选 1 项目模板 M3 —— 调研 + 规划，落地进行时）

**① 调研**（真实来源，r.jina.ai 直连抓取原文；web_extract 仍判「私有网络」被拦）：
- Scrivener 官方博客《Create Custom Templates for Your Scrivener Projects》https://www.literatureandlatte.com/blog/create-custom-templates-for-your-scrivener-projects ：内置 20+ 分类模板；Novel 模板＝稿件目录 + 示例首章 + 示例场景文本 + 角色/设定/参考分区；**任意项目可 File > Save as Template**（标题/分类/图标/是否存样式）；模板可导入/导出/设默认/「Reveal in Finder」——模板≈项目骨架快照，可社区分享。
- Obsidian 官方 Templates 核心插件 https://help.obsidian.md/plugins/templates ：模板＝**普通 markdown 文件**放在指定「模板文件夹」，插入时替换变量 `{{title}}/{{date}}/{{time}}`（可带 Moment 格式串），模板属性可与目标合并——模板＝纯文件、用户自定义、可分享。
- Manuskript README https://github.com/olivierkes/manuskript ：新建项目选 fiction/nonfiction 等「writing modes」模板，改变初始结构。
- 共性：模板＝可复用初始文档集（纯文件）；选择发生在「新建项目」时；用户可自定义；可分享。织卷取这一形态——**学 Obsidian「模板＝目录下的文件」，不学 Scrivener 的项目快照导入导出**（后者重，非当下价值）。

**② 规划**（本轮收敛，以下为设计定稿）：
- 形态：模板＝`<工作区>/模板/项目模板/<模板名>/` 下的文件目录，与项目内结构同构；纯本地明文、可入 git、分享＝拷目录；**零新依赖**。
- 内建「示例」模板：主进程幂等落档（与 `文档/` 同模式，只落空档不覆盖用户改动）；内容＝示例角色档案（基础设定＋切片小节）+ 示例世界观切片文件 + 带约定头的示例正文章——教 front matter/切片/目录约定，**中性示例，非任何作品的种子**。
- 新建项目对话框加「初始内容」：空白（默认＝现有行为）/ 示例 / 用户模板（扫描模板目录）；`createProject` 加**可选** template 参数（IPC 向后兼容）。
- 应用规则：先 `ensureSkeleton` + project.md（顺序不变），再从模板**补充复制**——跳过已存在文件、跳过 project.md 与 `.zhijuan/`，绝不覆盖已有内容。
- **不做**：`{{}}` 变量替换（无真实需求）；「另存为模板」＝把项目目录拷进模板目录（纯文件操作，文档里说明即可）；导入导出＝文件系统。
- 不动：`ensureSkeleton` 骨架默认文件、project.md 正文模板、proposals/slices/settings、其他层功能。
- 与「初始化引导」边界：模板＝**静态文件样例**（平台层）；ProjectGuide＝**交互填写引导**（体验层，`?guide=1` 链路不变）；两者正交，交叉登记到 04-体验层档案。
