## 一、范围（本线管什么）

- 创作上下文装配：`src/main/agent/context.ts`（buildWritingContext / buildProjectContext），块清单、预算硬控、截断策略、剥离注释口径；
- 预算常量：`src/shared/contextCaps.ts`（WCTX_CAPS / WCTX_MAX：正文 8000 / 前情 3000 / 人物 4000×4 / 切片 4000 / 章卡 2000 / 导演板 2500 / 素材 1200）；
- zj 工具层描述与可发现性（zj_list_docs / zj_read_doc / zj_search / zj_workspace / zj_edit_doc）；
- 长文记忆策略：前情承接（上一章尾部→同线前驱）、衰减/摘要化（M1.3 精神）、embedding 增强召回（预留）；
- 多线叙事下的装配语义（线内前驱 / 人物分线 / 切片分线，2026-09-16/17 已落地 49558e4、41c2105）。

## 四、候选（按优先级，下一轮开工先读本节）

1. **「上一章尾部」在 50 章+ 作品中的承接衰减评估**——当前策略=同线上一章尾部 ≤3000 字+现读补充；调研业界（Claude Code 记忆/摘要、长篇作者工具）后评估：是否需要「前文衰减摘要」（每 N 章自动产摘要、跨线多线时摘要粒），先出评估探针（同 context-outline-probe 先例，评估不作实现）。
2. **装配块口径复核**：多线落地后的块语义（片切注、「同线前驱」提示行）、预算分配是否仍合理（正文 8000 是否该随章长调）——对照真实项目数据（正文平均长度）后定，只调常量或口径，不动结构。
3. **zj 工具描述补「大纲」示例**（预防性，智能层档案观察项）——仅当真机/换模型出现「未开章问大纲答不出」且探针复跑失败时实现。
4. **embedding 增强召回**（M3 预留可选）：素材/人物按语义召回替代标签匹配；技术风险=依赖模型/嵌入服务，实施前先出成本与必要性评估。
