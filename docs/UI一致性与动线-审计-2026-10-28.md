# UI 一致性与动线审计（2026-10-28）

> 主人：「检查所有界面的 ux，看看有没有文字排版布局不一致的地方，我看设置里面有；可以借着这个改动优化整体的界面设计，让交互和用户动线更加合理。」

## 一、审计范围与方法

- 截图逐页目检：项目首页、正文创作、人物设定、世界观、大纲、时间线、素材库、设置四个分区（工作区 / 引擎 / 外观 / 关于）。
- 代码侧量化：`text-[Npx]` 与 `text-xs/sm/base` 使用分布（renderer 全量）。
- 对照既有规范：`docs/按钮与状态显示-规范.md`。

## 三、发现的其余不一致（按优先级，未在本轮改完）

### P1 · 字号阶梯失控
- 现状：`text-[11px]` 216 处、`text-[10px]` 115 处、`text-xs` 188 处、`text-sm` 88 处；同一层级在不同页面用 10/11/12 三种字号。
- 影响：跨页阅读时「元信息」轻重不一致；11px 中文在非 Retina 上偏糊。
- 建议阶梯：**20 页标题 / 14 标签与正文 / 12 辅助与元信息 / 11 仅徽标 / 10 仅数字角标**；11px 不再用于成句文案。
- 落地：先改高频页（设置、Agent、提案、审计抽屉），每页配截图对比，不一次性全局替换。

### P1 · 页面头不统一
- 时间线：居中窄栏 + 20px 页标题 + 副标题；设置：页标题 + 副标题 + 右侧主按钮；人物/素材：只有栏头，没有页标题。
- 建议：抽 `PageHeader(title, subtitle?, actions?)`，内容页统一「标题 + 一句说明 + 右侧操作」，栏头只承担列表名。

### P2 · 功能引导遮挡输入
- 首步引导气泡压在 Agent 输入框上（1/3 步），正好挡住「边聊边写」的入口。
- 建议：该步 `placement` 改上方 / 避让输入区，并在气泡出现时给输入框留 12px 安全距。

### P2 · 文档空态缺插图
- 人物/世界观/素材的空态没有插图（正文页有），视觉权重不一致。
- 建议：`DocSection` 增加 `art` 参数（character / world / material），由调用方传。

### P2 · 系统状态混进正文
- 大纲文档正文首行出现「状态：已回建」——这是系统态，不该写进作者文档。
- 建议：移到页头状态条（badge），文档只保留作者内容。

### P3 · 列表密度与元信息
- 章列行高约 68px、素材卡约 92px；密度差异可接受，但 meta 行字号需统一到 12px。
- Agent 面板头部三个 icon-only 按钮（盾/清单/时钟）可发现性弱，建议收进一个「⋯」菜单或补文字。

## 四、动线层面（下一步）

1. **检查 → 提案**已有统一入口；下一步把「检查结果」与「提案」在同一抽屉内分区（待确认 / 建议 / 已处理），减少跳转。
2. 首次进入项目：目前直接落在正文页空态；可提供「新建第一章」与「先建人物/世界观」两个起点，贴合「先设定后成文」与「先文沉淀设定」双闭环。
3. 设置页分区导航已有图标+说明，保持；把「写作引擎」里的连接检测结果做成可复制的诊断块（已有），并补「最近一次检测时间」。

## 五、规范草案（建议并入 `docs/按钮与状态显示-规范.md`）

- 字号：20 / 14 / 12 / 11（徽标）/ 10（数字角标）；成句文案不小于 12。
- 行高：标题 1.3、正文 1.6、辅助 1.5。
- 间距：卡片内 24、设置行 12（上下）、组间 24；同一列表内行距一致。
- 空态：标题 + 一句说明 + 一个主 CTA；插图按场景可选。
- 状态：中文、过去式/进行式明确（已完成 / 执行中 / 待派发 / 失败），不用英文枚举。
- 布局：内容页统一 PageHeader；列表栏头只写列表名与操作。
