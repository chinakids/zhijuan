# 织卷 · 键盘快捷键总表

> 权威总表（与 ⌘K 面板「键盘快捷键速查」、设置页「关于」入口同源，新增快捷键时两边同步更新）。
> 标准快捷键遵循 macOS 约定（Apple HIG Keyboards：https://developer.apple.com/design/human-interface-guidelines/keyboards）。

## 全应用

| 快捷键 | 动作 | 说明 |
|---|---|---|
| ⌘K | 命令面板（页面 / 章节 / 项目 / 素材全文搜索） | 任意页面可用；Esc 关闭 |
| ⌘S | 保存当前文档 | 正文页在编辑器焦点内有效（DocEditor 全局监听，Ctrl+S 亦触发） |
| Esc | 关闭当前浮层（查找条、命令面板、对话框） | 逐层关闭，不连锁 |

## 编辑（正文编辑器，Milkdown commonmark 内置）

| 快捷键 | 动作 | 来源 |
|---|---|---|
| ⌘Z / ⇧⌘Z / ⌘Y | 撤销 / 重做 | HIG 标准；Milkdown history 插件 |
| ⌘X / ⌘C / ⌘V | 剪切 / 复制 / 粘贴 | HIG 标准 |
| ⌘A | 全选 | HIG 标准 |
| ⌘B / ⌘I | 加粗 / 斜体 | Milkdown strong/em 默认键 |

## 查找（正文页）

| 快捷键 | 动作 | 说明 |
|---|---|---|
| ⌘F | 在正文中查找 | 打开查找条；有选区时预填选区文本，无选区保留上次词 |
| ⌘E | 用选区设置查找词 | HIG「Use the selection for a find operation」；不展开查找条，刷新高亮并定位第一处；无选区不动作 |
| ⌘G / ⇧⌘G | 下一处 / 上一处 | 查找条开着（⌘F 场景）或已有词/高亮（⌘E 场景）时都可用；循环绕回 |
| Esc | 结束本次查找 | 关闭查找条并清除高亮（⌘E 设置后未开查找条时同样生效） |

实现：`src/renderer/src/features/editor/finder.ts`（纯逻辑）+ FindBar.tsx + Prose.tsx 键盘监听；高亮走 CSS Custom Highlight API。

## 选中文字

| 操作 | 位置 | 说明 |
|---|---|---|
| 选中后浮层：「复制」「添加到对话」 | 编辑器内划词浮层 | 「添加到对话」= 作为引用进右侧 agent 对话（zj:quote-text 全局事件） |
| 右键菜单：剪切 / 复制 / 粘贴 / 全选 / 添加到对话 | 正文右键 | HIG Context menus：仅显示可用项 |

## 备注

- 织卷用 custom 标题栏（hiddenInset），macOS 系统菜单栏未注册应用级命令，因此快捷键的可发现性由 ⌘K 面板「帮助 → 键盘快捷键速查」与设置页「关于」入口承担（HIG：快捷键应便于发现）。
- 后续若接入系统菜单（平台层），快捷键文字应以本表为准同步。
