## 二、reduced-motion（HIG：Make motion optional / Let people cancel motion）

全部四通道在 `prefers-reduced-motion: reduce` 下关闭，分布：

- A：tokens.css `[class*='animate-in'], [class*='animate-out'] { animation: none !important }`（**注意：Radix 变体类名在 DOM 是 `data-[state=open]:animate-in`，覆盖必须用 `[class*=…]` 属性子串选择器，裸 `.animate-in` 匹配不到**）+ `.zj-sel-bubble`/`.zj-anno-pop` 各自 `@media reduce` 块。
- B：全局块本身在 `no-preference` 内（reduce 下无 transition 声明）。
- C：`.zj-card-lift` reduce 块 `transition: none` + `.zj-card-lift:hover { translate: none }`。
- D：tokens.css 末尾统一 reduce 块（zj-pulse-ring/zj-float/zj-flicker/zj-ind-arc → `animation: none`）。

## 三、已踩实的技术事实（改动效前必读）

1. **unlayered 覆盖 @layer utilities**：tokens.css 全局交互块是 unlayered，层叠优先级高于 `@layer utilities` 内**一切 Tailwind `transition-*` 类**（CDP 实测：写 `transition-all duration-200` 的组件运行时 computed transitionProperty 仍是全局块属性集）。**结论：组件里 `transition-*` 类在 button/a/[role=button] 上均为死类**，时长/曲线一律由全局块接管；要组件级特殊过渡（如 translate），必须造 unlayered 专项类（`.zj-card-lift` 先例）与全局块同级对抗。
2. **Tailwind v4 位移=原生 `translate` 属性**：getComputedStyle 读 `transform` 恒 none 会误判「动画没生效」——要读 `translate`（或其 CSS 产物 `translate: var(--tw-translate-x) var(--tw-translate-y)`）。
3. **SVG presentation attribute 不解析 CSS 变量**：`fill="var(--x)"` 无效，要用 `style`/样式对象（EmptyArt/LoadingIndicator 已踩）。
4. **浮层定位与 transform 动画冲突**：`.zj-sel-bubble` 有内联 `transform: translate(-50%, …)` 做居中定位，进场动画**只动 opacity**（zj-pop-in），做 transform 动画会把居中打飞。
5. **computed 多值解析**：`getComputedStyle` 多值以 `, ` 连接且 cubic-bezier 内部有逗号——`split(',')` 会拆碎，需 indexOf 扫描式比较。
6. **给频繁交互加明显动效 = 反 HIG**：@/命令菜单、tooltip 特意取 100ms 纯淡入；页面切换**决策不加转场**（React Router 直接替换，macOS 原生应用也非强制转场；理由见 17:15 轮档案）。

## 四、约定（新增动效时）

- 进场动画：覆盖层 150ms ease（与交互基线同量级）；高频浮层 ≤100ms 纯淡入；**不做退出动画**（关闭瞬时=可取消，不挡下一步；6 抽屉条件卸载，做退场要动挂载逻辑，明确不做）。
- 装饰动效：复用 tokens.css 样板类（zj-pulse-ring/zj-float/zj-flicker），必须带 `prefers-reduced-motion` 门控；SVG 内元素用 `transform-box: fill-box`。
- 验证：CDP getComputedStyle 读 animationName/时长/曲线 + `Emulation.setEmulatedMedia(prefers-reduced-motion=reduce)` 后应为 none；改 tokens.css 后跑 `motion-polish-ui-smoke.mjs`（进场通道）+ `motion-baseline-ui-smoke.mjs`（全局过渡/项目卡）回归。
