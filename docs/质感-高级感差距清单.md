# 质感 · 高级感差距清单（F-20260911-01 候选 0）

> 来源：主人 2026-09-11 群内反馈「应用缺少质感，视觉表现上不够高级」。
> 本清单是「质感/高级感专项」的逐条账本：改什么 / 不动什么 / 验收口径 / 状态。
> 原则：与「暖纸面 + 精密中性铬」设计语言共存，不推倒重来、不照抄苹果皮肤；
> 对照 Linear / Notion / Apple HIG 取「规范、细节、克制」，不是像素级移植。
> 每轮体验层推进器按本清单逐条推进，回执注明「质感专项 进度 N/M」。

## 参照与来源（真实调研）

- Apple HIG 十页调研（2026-09-10，见 04-体验层.md 迭代日志 3272e3e 轮）：Typography / Text views / Text fields / Toolbars / Sidebars / Keyboards / Context menus / Focus and selection / Motion / Windows（developer.apple.com/design/human-interface-guidelines）。
- **Material Design Empty states（2026-09-11 20:15 轮，V-05）**：https://m2.material.io/design/communication/empty-states.html（r.jina.ai 抓取，/tmp/m2-empty.md）。要点：空态=非交互图片+tagline；图片中性/与品牌一致；tagline 不要像可点击 CTA；备选=starter/educational/best match。Apple HIG 无独立 empty-states 页（404 实证）。
- Linear 设计系统解读（2026-09-11 14:15 轮）：https://www.shadcn.io/design/linear（DESIGN.md 摘要，经 r.jina.ai 抓取原文）；Linear UI 重设计回顾 https://linear.app/now/how-we-redesigned-the-linear-ui。
  - 吸取要点：**层级靠「表面阶梯 + 发丝线」承载，阴影只做轻浮（surface ladder over shadows）**；单一强调色克制使用；字重上限 600（Linear 不用 700）。
- **Apple HIG Buttons（2026-09-12 02:15 轮，V-04）**：https://developer.apple.com/design/human-interface-guidelines/buttons（无头 Chrome CDP 9224 抓 innerText）。要点：按钮=风格/内容/角色三要素；符号要成体系、同场景规格一致（SF Symbols 自动着色）；方形按钮前置符号；避免混用不同符号规格。
- **Lucide stroke width（2026-09-12 02:15 轮，V-04）**：https://lucide.dev/guide/lucide/basics/stroke-width（CDP 抓取）：官方默认 strokeWidth=2px（24px 网格设计基线）；第三方缩放规则（prahsys.com/brand-guidelines/icons：stroke≈尺寸/12，16px≈1.33px）仅供参考——**本轮不动描边（保留官方 2px），只统一尺寸治理**。
- **织卷图标规范（V-04 定）**：**图标尺寸由容器决定（单一来源）**——shadcn Button 内 icon 不写尺寸类：基类 `[&_svg]:size-4`=16px（text-sm+/图标按钮标准）；紧凑按钮（h-7 + text-[11px]/text-xs）用 `[&_svg]:size-3`=12px；size="sm"（h-8 text-xs）用 `[&_svg]:size-3.5`=14px；raw button/行内 icon 保留显式类（无容器覆盖，有效口径）。**根因（已实证）**：Button 基类 `[&_svg]:size-4`（特异性 0,1,1）覆盖 icon 显式 `h-3`（0,1,0）——Button 内 icon 尺寸类全是死代码，实际一律 16px。
- Notion / Obsidian / iA Writer 书写体验：前期调研已在 04-体验层.md 候选 1（I4 侧栏）相关轮次引用。
