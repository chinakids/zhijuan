# 功能引导（用户动线引导）· 产品设计（2026-09-23 主人提出）

> 主人要求：「用户动线上需要增加功能引导能力。」目标：让新用户沿核心创作动线快速上手，且不打扰熟练用户。
> 本文档为方案权威源；实现按周交付窗口排期（体验层主责 + 平台层配合持久化/开关）。

## 一、现状盘点（已有哪些引导，复用为主）
- **ProjectGuide**（新建项目引导）：世界观 → 主要角色 → 进入正文（已有，保留并作为「首次上手」主入口）。
- **空态引导**：各页 EmptyState 文案（如「还没有选中章节」）+ 首页空态、项目空态。
- **快捷指令**：输入区 chips（续写/润色/延伸/巡查/导演）；检查阵容菜单；状态栏体检（有问题即提示）。
- 缺：**跨页面主动线的显式步骤引导** 与 **单功能点的高亮提示（coach mark）**——新手容易不知道「先写、再保存、同步出提案、去大纲导导演」。

## 二、目标与原则
1. **动线引导**：覆盖「从空项目到写出第一段」核心路径 + 各核心能力首次使用提示。
2. **不打扰**：默认对「功能引导」开一次，做过即不再弹（持久化 seen 标记）；**设置页提供开关**「首次使用引导」+「重新查看引导」，尊重熟练用户与可回放。
3. **非阻塞**：引导=高亮目标元素 + 定位气泡 + 「下一步 / 跳过」，绝不锁界面、不挡操作（HIG Popovers/Tour 口径）。
4. **按阶段触发**：阶段未满足不弹（如未建项目不引导正文页）。

## 三、引导内容（动线清单）
| # | 动线节点 | 形态 | 出现条件 |
|---|---|---|---|
| 1 | 新建项目 → 首次进入工作区 | ProjectGuide（现状） | 新项目首次 |
| 2 | 正文页：写/续写入口 | Coach mark 指向「右侧 agent 输入区」+ 提示划词引用 | 首次进入正文页且已有章节 |
| 3 | 保存 → 切片同步 | 气泡提示「保存会触发切片同步，设定改动走提案」 | 首次保存 |
| 4 | 提案出现 | 高亮「导航底部『待确认提案』」 | 首次有提案 |
| 5 | 大纲「导演本章」 | 高亮顶栏 icon + 说明 | 首次进入大纲且已有章卡 |
| 6 | 批注入口 | 高亮划词浮层「批注」按钮 | 首次划词（可并入划词提示） |
| 7 | 检查阵容 | 指向「检查 ▾ / 规则体检状态栏」 | 首次进入 Agent 区 |

## 四、实现方案
- **机制**：`features/guide/` 下加 `TourStep` 组件（高亮 ring + 定位气泡 + 下一步/跳过，复用现有工具提示与 HIG Popovers 布局），一个 `useTour` hook 管理单步骤/多步骤序列与「当前步骤可见性」（元素存在才显示，避免找不到目标）。
- **持久化**：`~/.hermes/… `？ 不——织卷数据侧：`userData/zhijuan-guide.json`（记录每步 seen 时间）；**设置页开关** `AppSettings.guideEnabled`（默认 true，首次）；「重新查看引导」重置 seen。
- **触发**：各页挂载时检查 seen 与条件，按需弹第一步；done 或 skip 写 seen。
- **不新增重依赖**：与 ProjectGuide/EmptyState/现有组件复用，零新 UI 库。

## 五、验收口径
- 首启/新项目进入 → 动线引导 1-7 依条件出现，可「下一步/跳过」，跳过/完成不再弹；
- 设置页可关闭与重放；关闭后新项目也不弹；
- 冒烟：`guide-tour-ui-smoke`（首次出现/跳过写 seen/重看再出现/关闭不弹 四断言）+ 三道门。

## 六、排期
- 拆 2 个周增量：① 机制（TourStep/useTour/persist/设置开关）+ 步骤 1-3；② 步骤 4-7 + 冒烟 + 走查。可先落步骤 1-2（复用 ProjectGuide 起手），随后补齐。
- 主责体验层；设置开关/持久化与平台层 I 协作（同 annotations 开关先例）。
